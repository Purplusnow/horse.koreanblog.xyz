# 구글애즈 광고 소재 — horse.koreanblog.xyz

최종 업데이트: 2026-10-14

머신러닝 경마연구소(horse.koreanblog.xyz) 구글애즈 집행용 소재 묶음입니다.
숫자는 모두 **라이브 사이트에서 그대로 확인되는 값**이며 출처는 `numbers.json`에
적어 두었습니다. 주말 집계로 수치가 바뀌면 `numbers.json`을 고치고
`python3 ads/make_banners.py`를 다시 돌리면 배너가 따라옵니다. 텍스트 소재의
숫자는 이 문서에서 직접 고쳐야 합니다.

## 0. 먼저 읽을 것 — 심사 리스크

구글애즈 **도박 및 게임 정책**은 마권·배당·적중 정보를 다루는 사이트를
"도박 관련 콘텐츠"로 분류합니다. 한국은 구글이 도박 광고를 허용하는 국가
목록에 없어서, **배당·적중을 전면에 내세운 A세트는 반려될 가능성이 작지
않습니다.** 반려 자체는 계정에 치명적이지 않지만 같은 소재를 반복해서 올리면
계정 정지로 이어질 수 있습니다.

그래서 두 세트로 나눠 두었습니다.

| 세트 | 성격 | 쓰임 |
|---|---|---|
| **A — 고배당 성과형** | 350.2배·53.1% 등 숫자 전면 | 클릭률은 높지만 심사 리스크 큼. 소액 별도 캠페인으로 시험 |
| **B — 통계·기록형** | 데이터·출주표·기록 아카이브 | 반려 가능성 낮음. **여기부터 시작 권장** |

운영 순서 권장: **B세트로 캠페인을 먼저 승인받아 계정 이력을 쌓고**, 1~2주 뒤
별도 광고그룹에 A세트를 소액으로 올려 승인 여부를 본다. A가 반려되면 그 광고만
삭제하고 B는 그대로 돈다.

랜딩 쪽 요건은 이미 충족돼 있습니다 — 푸터에 만 19세 이상 고지, 한국도박문제
예방치유원(1336) 안내, "적중을 보장하지 않는다"는 문구가 들어 있습니다.

| 항목 | 값 | 이유 |

| 언어 | 한국어 | |
| 입찰 | 클릭수 최대화 + 상한 CPC 300~500원 | 전환 데이터가 쌓이기 전 단계 |
| 일 예산 | 1~2만원 | 경주일(금·토·일)에 집중 소진 |
| 광고 일정 | 목 18시 ~ 일 18시 | 출전표 공개~경주 종료 구간. 주중은 검색량이 거의 없습니다 |
| 기기 | 모바일 +20% | 경마 정보는 현장·모바일 소비가 압도적 |

### 전환 설정이 아직 비어 있습니다

사이트 GA4는 지금 `page_view`만 보냅니다. 입찰을 "전환수 최대화"로 올리려면
먼저 GA4에서 주요 이벤트를 만들어 구글애즈로 가져와야 합니다. 가장 쓸만한 두 개:

- **경주 상세 조회** — `page_view` 중 `page_location`에 `/race/` 포함
- **지면 열기** — `page_location`에 `/paper/` 포함

둘 다 "이 사람이 예상을 실제로 읽었다"는 신호라 광고 최적화 기준으로 적절합니다.

## 7. 소재 갱신 체크리스트 (2주에 한 번)

1. `https://horse.koreanblog.xyz/accuracy/` 와 `/tier/strong/` 에서 숫자 확인
2. 바뀌었으면 `ads/numbers.json` 수정 → `python3 ads/make_banners.py`
3. 이 문서의 A세트 헤드라인·설명에 박힌 숫자(53.1% / 76.5% / 482경주 / 350.2배)도 같이 수정
4. 홈의 "역대 고배당" 1위가 바뀌었으면 A소재 전부 재생성

광고에 적힌 숫자가 랜딩과 다르면 심사에서 걸릴 뿐 아니라, 보러 온 사람이
가장 먼저 발견합니다.
